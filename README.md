# 🎡 วงล้อสุ่มชื่อนักเรียนในห้องเรียน (Classroom Wheel of Names)

เว็บแอปพลิเคชันสำหรับสุ่มชื่อนักเรียนในห้องเรียน ออกแบบมาเพื่อการเรียนการสอนโดยเฉพาะ สวยงามในโทนสีฟ้าสดใส ใช้งานง่าย **ไม่มีโฆษณา** ตัวอักษรขนาดใหญ่อ่านง่ายบนจอสมาร์ททีวีและโปรเจกเตอร์

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 🎡 **วงล้อฟิสิกส์ลื่นไหล (Smooth Canvas Wheel)**: วาดภาพระดับ High-DPI คมชัด ไม่แตกบนจอ 4K / โปรเจกเตอร์
- 🔊 **ระบบเสียงสมจริงในตัว (Web Audio API)**: มีเสียงเข็มหมุน (Ticker) และเสียงไชโยฉลองชัยชนะ (Fanfare) โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก โหลดเร็ว เล่นได้แม้ออฟไลน์
- 🎉 **พลุกระดาษเฉลิมฉลอง (Confetti Celebration)**: แสดงความยินดีกับผู้ได้รับเลือก พร้อมตัวเลือก "ลบชื่อออก" หรือ "เก็บชื่อไว้"
- 🏫 **จัดการรายชื่อหลายห้องเรียน (Multi-Class Presets)**: บันทึกและสลับห้องเรียน เช่น ม.1/1, ม.2/3, กลุ่มกิจกรรม ได้อย่างสะดวกรวดเร็ว ข้อมูลไม่หายเมื่อรีเฟรช
- 👥 **ระบบสุ่มแบ่งกลุ่มนักเรียน (Classroom Group Maker)**: สุ่มจัดกลุ่มนักเรียน 2–10 กลุ่ม พร้อมปุ่มคัดลอกผลลัพธ์ในคลิกเดียว
- ⚡ **ระบบสุ่มแบบด่วน (Quick Picker)**: สุ่มจับชื่อทันใจโดยไม่ต้องหมุนวงล้อ
- ⛶ **โหมดเต็มหน้าจอ (Fullscreen Mode)**: เหมาะสำหรับการแสดงผลบนจอหน้าชั้นเรียน / สมาร์ททีวี
- ⌨️ **รองรับคีย์บอร์ด**: กดปุ่ม `Spacebar` หรือ `Enter` เพื่อหมุน, `F` เพื่อเปิดเต็มจอ, `Esc` เพื่อปิดป๊อปอัป

## 🚀 วิธีการนำขึ้นทดลองใช้บน Vercel (Deploy on Vercel)

โปรเจกต์นี้ถูกออกแบบเป็น **Static Web App** 100% จึงสามารถ Deploy บน Vercel ได้ฟรีและเสร็จสิ้นภายใน 1 นาที:

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ)
1. เข้าไปที่ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบด้วย GitHub
2. คลิกปุ่ม **"Add New..."** -> **"Project"**
3. เลือก Repository `santi-7051/Wheelofname`
4. ในส่วน Framework Preset เลือกเป็น **"Other"** (หรือปล่อยเป็นค่าเริ่มต้น)
5. คลิกปุ่ม **"Deploy"**
6. ระบบจะสร้าง URL เว็บไซต์พร้อมใช้งานทันที (เช่น `https://wheelofname-xxx.vercel.app`)

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
Wheelofname/
├── index.html          # โครงสร้างหน้าเว็บหลักและ Modal ต่างๆ
├── css/
│   └── style.css       # ดีไซน์โทนฟ้าสดใส ฟอนต์ Kanit สไตล์โมเดิร์น
├── js/
│   ├── audio.js        # เครื่องมือสร้างเสียงสังเคราะห์ Web Audio API
│   ├── confetti.js     # ระบบเอฟเฟกต์พลุกระดาษเฉลิมฉลอง
│   ├── storage.js      # จัดการข้อมูลห้องเรียนและบันทึกประวัติ LocalStorage
│   ├── wheel.js        # การคำนวณฟิสิกส์และการวาดวงล้อ Canvas
│   └── app.js          # ส่วนควบคุมแอปพลิเคชันและการเชื่อมต่อ Event
├── vercel.json         # การตั้งค่า Cache & Security สำหรับ Vercel
├── .gitignore          # ไฟล์ที่ไม่ต้องการให้อัปโหลด
└── README.md           # คู่มือการใช้งานโปรเจกต์
```

## 💻 พัฒนาและทดสอบในเครื่อง (Local Development)

สามารถเปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ได้ทันที หรือใช้ Live Server:

```bash
# ทดสอบด้วย Python Simple HTTP Server
python -m http.server 8000
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
